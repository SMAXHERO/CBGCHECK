# 藏宝阁数据面板（阴阳师 · 角色）

把藏宝阁的账号列表变成一块好用的数据面板：**73 项条件实时筛选**、8 项 KPI 指标、四类图表、14 列明细表排序分页、多账号横向对比、Excel / CSV 导出与 A4 打印，支持深色 / 浅色主题，**查询中途可随时取消**。

数据不是抓下来的静态文件，而是**每次点「查询」时实时拉取**。

> ### 🚀 想直接用？看 **[docs/getting-started.md](docs/getting-started.md)**
>
> 从零到能用的完整步骤（装什么、在哪敲、看到什么才算对、出问题怎么查），照着做约 10 分钟。
>
> 最短路径：装 Node.js → 下载本项目 → 双击 `start.bat` → 在弹出窗口里登录藏宝阁
> → 打开 https://smaxhero.github.io/CBGCHECK/ 并点「允许」。

> **✅ 线上地址可以直接用（需要点一次「允许」）**
>
> 已部署地址：**https://smaxhero.github.io/CBGCHECK/**
>
> 打开时浏览器会提示**「是否允许访问本地网络上的设备」**（Chrome 142+ / 新版 Edge 的
> 「本地网络访问」权限）：
>
> | 你的选择 | 结果 |
> |---|---|
> | **允许** | 面板自动连上你本机的伴随服务，**实时查询全部可用** |
> | 拒绝 / 忽略 | 显示「未探测到本地查询服务」的引导页 |
>
> 所以这个公网页面是**真正能用的面板**，不只是展示位。前提只有一个：
> **你自己本机正在运行伴随服务并已登录藏宝阁**——它访问的是本机服务，不是某个云端后端。
>
> **别人打开同一个地址**也一样能用，但用的是**他自己机器上**的服务与账号；
> 没有本机服务的人只会看到引导页。这是浏览器的权限设计，不是 bug。
>
> ⚠️ **安全提醒**：服务当前允许任意来源调用且无口令。若你曾对某个页面点过「允许」，
> 那个页面就具备调用你本机服务的能力。详见「已知限制」一节的说明与缓解办法。

## 它长什么样

左侧条件面板（13 组 / 73 项，与原筛选助手同一套定义）＋ 右侧数据区：

- **KPI**：命中数量、价格中位数与四分位、最快散件/招财一速、平均签到、SSR 与六星均值、高战号占比
- **图表**：价格分布直方图、散件一速分段、平台占比环形图、价格 × 签到年数散点（对数轴）
- **明细表**：14 列可排序、分页、服务器列筛选、行勾选对比、展开看全部亮点标签
- **导出**：Excel / CSV（带 UTF-8 BOM，Excel 不乱码）、打印 A4 横向 PDF（表头每页重复）
- **查询可取消**：一次查询最多 8 页、页间节流 4 秒，跑满要 30 秒以上。中途想改条件时，
  底部按钮会变成「取消查询」，点下去**不到 1 秒**就停（实测 0.44 秒），
  已取到的部分结果保留下来可以照常看图表和导出，界面上会明确标注**结果不完整**。
  取消后可以立刻重新查询，不会撞上「已有查询在进行中」。

## 数据的来源与更新

| 数据 | 来源 | 更新方式 |
|---|---|---|
| **查询结果** | 每次点「查询」实时拉取 | 自动，无需维护 |
| **区服清单**（6 组 / 131 条） | 藏宝阁公开的 `server_list_data*.js` | ✅ 脚本自动同步，开新区后跑一次即可 |
| **条件定义**（13 组 / 73 项） | 从 `cbg-filter-kit` 一次性导出 | ⚠️ 需手工重新导出 |

```bash
# 检查有没有新增区服（0=最新，1=有差异）
python tools/cbg/sync_servers.py --check

# 同步区服（含游戏内通道的额外分组）
python tools/cbg/sync_servers.py --write --include-ingame
```

条件定义为什么会过期、怎么更新，详见 **[docs/filter-sources.md](docs/filter-sources.md)**。

## 它是怎么工作的

```
浏览器（本机打开）
   │  POST /api/search      ① 发起查询
   │  GET  /api/result      ② 轮询进度
   ▼
本机伴随服务 127.0.0.1:8791
   │  Chrome DevTools Protocol
   ▼
一个受控的 Edge 窗口（你在这里登录一次藏宝阁）
   │  在页面上下文里 fetch，带着你自己的会话
   ▼
藏宝阁 /cgi/api/query
```

**为什么要这么一个本地服务**：藏宝阁的搜索接口要求登录态，而浏览器 Cookie 按域名隔离——
任何部署在别处的网页都拿不到 `cbg.163.com` 的会话。这是浏览器的安全规则，不是实现问题。
所以「带会话的请求」只能由本机一个受你控制的真实浏览器发出。

这个方案**不绕过任何校验**：请求由页面自己发，带着你自己的登录凭据，
和你在藏宝阁网站上手动搜索没有区别。工具不读取、不保存你的账号密码。

## 快速开始

环境要求：Node.js ≥ 20（用于面板与伴随服务），Python ≥ 3.9（可选，仅核对脚本用）。

**第一步：启动伴随服务**（会弹出一个独立的 Edge 窗口）

```bash
node tools/cbg/scraper-service/server.mjs
```

在那个窗口里**登录一次藏宝阁**。登录态存在 `tools/cbg/scraper-service/profile/`
（独立的浏览器用户目录，不碰你日常浏览器的数据与标签页），之后重启服务依然有效。

**第二步：启动面板**

```bash
cd cbg-web
npm install
npm run dev          # http://127.0.0.1:5173
```

打开后会自动探测服务并查询一次。默认条件是**价格 500~1500 元 + 散件一速 ≥158 + 勾玉 ≥100000**，
可在 `cbg-web/src/config/defaults.ts` 里改。

服务还没起来时，页面会显示启动指引，**不会**显示任何旧数据。

页数上限与节流节奏都可以调（默认 8 页 / 4 秒，实测累计约 250 条会触发站点安全验证）：

```bash
node tools/cbg/scraper-service/server.mjs --max-pages 4 --delay 5000
```

## 别人怎么用这个仓库

三种用法，**绝大多数人只需要第一种**。完整说明见 **[docs/self-host.md](docs/self-host.md)**。

| 用法 | 一句话 | 需要什么 |
|---|---|---|
| **① 直接用公网地址** | 最省事：本机跑起伴随服务，浏览器打开线上地址、点「允许」 | Node.js ≥ 20、Edge/Chrome |
| **② clone 到本机自己用 / 改代码** | 界面跑在本机 `127.0.0.1:5173`，方便改 | 同上 + `npm install` |
| **③ Fork 部署到自己的 Pages** | 得到一份属于自己的部署地址 | 仓库设为 Public，Pages 选 GitHub Actions |

**跨机器共用是做不到的**：那个「允许访问本地网络」的授权，授权对象是
**「这台电脑的 127.0.0.1」**——所以每个人用的都是**自己机器上的服务和自己登录的账号**。
你把地址发给朋友，他用的是他机器上的服务；他没跑服务，就只看到引导页。

> 想改代码前，建议先读 [cbg-web/README.md](cbg-web/README.md) 的「开发时踩过的坑」一节——
> 里面记了几个**不报错、只安静给出错误结果**的陷阱（参数倍率、两个长得一样的商品 ID、
> Effect 依赖导致的无限更新循环等）。

## 已知限制

| 限制 | 说明 |
|---|---|
| 公网版需要「允许」授权 | 首次打开公网地址时，浏览器会问是否允许访问本地网络；允许后才能连上你本机的服务。拒绝则显示引导页 |
| 公网版依赖你的电脑开着 | 它连的是你本机的伴随服务，不是云端后端。电脑关机 / 服务没启动，公网页面就查不了 |
| 服务无访问口令 | CORS 允许任意来源，任何你点过「允许」的页面都能调用它。见下方「安全提醒」 |
| 「勾玉」等条件不生效 | 列表接口不返回这些字段（它们属于商品详情数据）。界面会明示「N 项条件未生效」，不会假装筛过 |
| 抓取速度受限 | 实测累计约 250 条会触发站点安全验证，所以默认 4 秒/页、单次最多 8 页（120 条）。被拦后需在浏览器里手动过验证并等冷却。**中途可用「取消查询」随时停下** |
| 取消不能中断已发出的那一页请求 | 请求由页面里的 `fetch` 发出，服务发不了 abort 信号。最坏情况是「当前这页取完就停」（通常不到 1 秒，极端 20 秒超时） |
| 需要手动登录一次 | 登录这一步没法也不该自动化——工具全程不接触、不存储你的账号密码 |
| 条件定义会过期 | `filters.json` 是手工导出的快照。藏宝阁新增条件时界面不会自动出现，需重新导出。区服清单不受影响（可脚本同步） |

### 安全提醒：关于「本地网络访问」权限

浏览器把这个权限交由用户决定，于是产生一个实际风险：**任何你点过「允许」的页面，
都获得了调用你本机服务的能力**。如果那个页面是恶意站点，它可以在你无感知的情况下
反复查询你的服务（消耗你的账号风控额度）。

当前的缓解办法：

1. **只对你信任的页面点「允许」**——公网地址、本机地址是可信的；陌生站点一律拒绝
2. **不用时关掉伴随服务**（终端里 `Ctrl+C`）——授权还在，但已无处可查，这是最有效的一招
3. 在地址栏左侧的站点设置里，**撤销**不信任站点的本地网络权限

> 本项目按设计**不带访问口令**：它假定运行在个人机器上、并由使用者自行控制授权。
> 如果你打算把它暴露给更多人使用，应该自行加一层鉴权（例如在服务端校验一个自定义请求头）。

## 数据与合规

- 抓取的是**藏宝阁公开列表页的聚合信息**（价格、区服、一速、签到天数这类账号属性）；
- 请求由**你自己已登录的浏览器**发出，登录态只存在本地被 git 忽略的目录里；
- 请控制频率（默认已做节流），不要高频批量抓取；
- 仅供个人比价参考，**不要用于商业用途或二次分发数据**。请遵守藏宝阁用户协议，
  因使用不当导致的账号风险由使用者自行承担。
