这套布局怎么支撑第二个模块

下面每一条都可以直接沿用，不需要为第二个模块另写一套样式。

  1. 顶部 Tab 切模块：Tab 里带条件项数；每个模块有自己的主色（当前角色是珊瑚红，模块二是青色），切过去色相就变，一眼知道在哪。
  2. 左侧分组由模块自定义：面板外壳（搜索框、展开全部、卡片折叠）是共用组件，里面装哪些分组由模块的 schema 决定。第二个模块可以有完全不同的分组结构。
  3. 模块副标题条：Tab 下面一条细带，写当前模块的口径与统计项数量。觉得多余可以去。
  4. 右侧版式固定：KPI 固定 4 列（8 张正好两行）、图表 3 列 + 一行全宽、表格在下方。第二个模块换内容不换版式，看起来就是同一个产品。
  1. 条件与结果按模块隔离：各模块的勾选条件、查询结果、默认条件互不干扰，来回切不会丢。
  2. 底部控制台共用：查询 / 取消查询 / 导出 / 打印这一条不分模块，逻辑只有一份。
  3. 同类元素尺寸必须一致：所有按钮 36px 高（无边框的用 border:1px solid transparent 占位）、所有图表画布同高、所有卡片同高。
  4. 栅格列写 minmax(0,1fr)：写 1fr 会被内容撑开而不收缩，窄屏下就溢出被裁——这是实测踩过的坑。
