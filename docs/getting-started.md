# 从零到能用：完整流程

本文是**照着做就行**的操作手册。每一步都写清了：**在哪做、敲什么、看到什么才算对**。

预计耗时：第一次约 10 分钟（其中登录藏宝阁占 2~3 分钟）。

---

## 先理解一件事（30 秒）

```
你的浏览器 ──打开──▶ 界面（GitHub 上的静态网页，谁都能打开）
                        │
                        │ ①浏览器问你「是否允许访问本地网络」→ 点【允许】
                        ▼
                   你电脑上的查询服务（127.0.0.1:8791）
                        │
                        │ ②它借用一个已登录藏宝阁的浏览器去发请求
                        ▼
                      藏宝阁
```

两个关键点：

- **界面在公网上，服务在你电脑上。** 那个公网地址不是"某人的服务器"，只是一张网页。
- **每个使用者都在用自己电脑上的服务、自己登录的账号。** 所以别人关机不影响你，你关机也不影响别人。

---

## 第 1 步：确认你在这台电脑上（一次性）

本文所有操作都在**你要用来查询的那台电脑**上完成。

- ✅ 正确：在你自己的笔记本上操作
- ❌ 错误：以为"打开网页就行"，什么都不装

---

## 第 2 步：安装 Node.js（一次性，约 3 分钟）

**为什么**：查询服务是一个 Node 程序，没它就跑不起来。

**在哪做**：浏览器 + 安装程序。

1. 打开 https://nodejs.org/zh-cn
2. 下载 **LTS** 版本（左边那个按钮，别选 Current）
3. 双击安装，一路「下一步」即可（默认选项都对）
4. **验证**：按 `Win + R`，输入 `cmd` 回车，在黑窗口里敲：

   ```
   node -v
   ```

   ✅ 看到 `v20.x.x` 或更高的版本号 = 成功
   ❌ 提示 `'node' 不是内部或外部命令` = 没装成功，或装完没重开窗口（关掉黑窗口重新开一个再试）

> macOS / Linux 用户：官网下载对应的 pkg，或用 `brew install node` / 发行版包管理器。后面把 `.bat` 换成手动敲命令即可。

---

## 第 3 步：把项目下载到电脑上（一次性，约 1 分钟）

**为什么**：查询服务的代码在里面。

**在哪做**：浏览器，或终端。

### 方式 A：下载 ZIP（最简单，不用装 git）

1. 打开 https://github.com/SMAXHERO/CBGCHECK
2. 点绿色 **Code** 按钮 → **Download ZIP**
3. 解压到一个**路径里没有中文和空格**的位置，例如 `D:\CBGCHECK`

### 方式 B：用 git clone（已经装了 git 的话）

```
git clone https://github.com/SMAXHERO/CBGCHECK.git D:\CBGCHECK
```

> 建议放在 `D:\CBGCHECK` 这类简单路径。**不要**放在 `C:\Program Files\` 下面（可能没有写权限），
> 也**不要**放在桌面（路径常含中文）。

---

## 第 4 步：启动查询服务（每次要用时，约 20 秒）

**为什么**：它负责拉起浏览器、借用你的登录态去查藏宝阁。

**在哪做**：项目文件夹里。

### 方式 A：双击启动器（推荐）

打开 `D:\CBGCHECK` 文件夹，**双击 `start.bat`**。

它会依次：检查 Node.js → 启动查询服务 → 等服务就绪 → 打开公网界面。看到这些就对了：

```
[OK] Node.js v20.x.x
[OK] Starting the query service, please wait...
[OK] Service is ready.
```

（启动器用英文提示，是为了避免不同系统语言下的中文乱码；说明都在本文里。）

如果服务**已经在运行**，它会识别出来并跳过重复启动，显示 `[i] Service is already running`。

### 方式 B：手动敲命令

在 `D:\CBGCHECK` 文件夹的地址栏里输入 `cmd` 回车（这样打开的命令行就在当前目录），然后：

```
node tools\cbg\scraper-service\server.mjs
```

✅ 看到这些输出 = 成功：

```
  藏宝阁实时查询服务已启动
    接口地址   http://127.0.0.1:8791/api/health
    目标站点   https://yys.cbg.163.com/
```

⚠️ **这个窗口不要关**，关了服务就停了，网页就查不到数据了。

---

## 第 5 步：登录藏宝阁（一次性，约 2 分钟）

**为什么**：藏宝阁的查询接口要求登录态。这一步没法自动化，也不该自动化——
工具全程不接触、不保存你的账号密码，只使用你手动登录后的会话。

**在哪做**：第 4 步自动弹出的那个**独立浏览器窗口**（标题是藏宝阁，地址栏是 `yys.cbg.163.com`）。

1. 在那个窗口里用你平时的方式登录藏宝阁
2. 如果出现**滑块验证**，拖动滑块完成
3. 登录成功后，**那个窗口可以不管它**（让它在后台待着就行），但**不要关掉**

> 登录态保存在 `tools\cbg\scraper-service\profile\` 这个目录里，
> 是服务专用的浏览器数据目录，**不碰你日常浏览器的标签页、插件和登录信息**。
> 登录一次长期有效，除非藏宝阁让它过期。

---

## 第 6 步：打开界面并使用（每次）

**在哪做**：你日常的浏览器。

### 6.1 打开地址

```
https://smaxhero.github.io/CBGCHECK/
```

### 6.2 点「允许」

第一次打开时，浏览器会问：

> 「smaxhero.github.io 想访问本地网络上的设备」

**点【允许】** —— 这是浏览器的新权限（Chrome 142+ / 新版 Edge 的「本地网络访问」）。

| 你的选择 | 结果 |
|---|---|
| **允许** | 界面连上你电脑上的服务，开始查数据 ✅ |
| 拒绝 | 显示「未探测到本地查询服务」的引导页 ❌ |

如果误点了拒绝：点地址栏左侧的**站点设置图标**（锁或滑块图标）→ 找到「本地网络访问」→ 改成允许 → 刷新页面。

### 6.3 看到这些就说明通了

| 位置 | 应该看到 |
|---|---|
| 顶部（标题旁） | 一个**绿点** + `实时` |
| 左侧 | 13 个条件分组（区服、公示期、价格…） |
| 底部 | `已选 N 项 ｜ 命中 M 条` |

第一次打开会自动查一次，默认条件是**价格 500~1500 元 + 散件一速 ≥158 + 勾玉 ≥100000**。

### 6.4 日常操作

| 想做什么 | 怎么做 |
|---|---|
| 换条件查询 | 左侧勾选条件 → 点右下角**「查询」**（条件改了不会自动重查，这是为了避免触发风控） |
| 排序 | 点表头（价格、一速、签到、收藏…） |
| 只看某服务器 | 表头「服务器 / 大区」列的小漏斗 |
| 对比几个号 | 点表格行勾选 → 底部弹出对比清单 |
| 导出 | 底部「导出 Excel」/「导出 CSV」 |
| 打印 / 存 PDF | 底部「打印 / PDF」（A4 横向，表头每页重复） |
| 看某账号原页 | 点表格里的标题（跳转藏宝阁） |
| 换深浅色 | 右上角太阳 / 月亮图标 |

## 第 7 步：用完怎么关

| 操作 | 效果 |
|---|---|
| 关掉那个黑窗口（或在里面按 `Ctrl+C`） | **服务停止**。网页会显示引导页，不再能查询 |
| 关掉那个藏宝阁浏览器窗口 | 服务还在，但下次查询可能因为浏览器被关而失败——建议由服务自己管这个窗口 |
| 关电脑 | 同上，服务停止。**这不影响别人**，因为他们用自己的服务 |

**建议**：不用的时候把服务关掉。理由见下面的「安全」。

## 遇到问题怎么查

| 现象 | 原因与处理 |
|---|---|
| 网页顶部是灰点 / 显示「没探测到本地查询服务」 | 服务没启动，或没点「允许」。先确认第 4 步的窗口还开着；再确认浏览器权限 |
| 顶部是黄点 + `需登录` | 登录态过期了。回到第 5 步的浏览器窗口重新登录 |
| 顶部是黄点 + `需滑块验证` | 触发风控了。等 2~5 分钟，到那个浏览器窗口里打开任意商品页完成滑块，再回网页点「查询」 |
| 查询很慢 | 正常。为了避免风控，服务做了节流：**每页 4 秒、单次最多 8 页（120 条）**，一次完整查询约 30 秒 |
| 查不到「勾玉」等条件 | 藏宝阁列表接口不返回这些字段（属于商品详情数据）。界面会明示「N 项条件未生效」，不会假装筛过 |
| 双击 `start.bat` 一闪而过 | 说明报错了。改为按第 4 步的**方式 B** 手动敲命令，就能看到具体错误 |
| `node` 命令找不到 | 没装 Node.js，或装完没重开命令行窗口 |

## 安全须知

**「允许访问本地网络」这个授权是给站点的。** 你一旦对某个页面点了「允许」，
那个页面就获得了调用你本机服务的能力。所以：

1. **只对你信任的页面点「允许」**——本文里的公网地址、以及你自己的 `127.0.0.1` 是可信的
2. **不用时关掉服务**——这是最有效的一招：授权还在，但已无处可查
3. 想撤销：地址栏左侧的站点设置里，把「本地网络访问」改回「询问」或「阻止」

本项目**按设计不带访问口令**（假定运行在个人机器上、由使用者自行控制授权）。
如果你打算把它暴露给更多人用，应自行加一层鉴权。
